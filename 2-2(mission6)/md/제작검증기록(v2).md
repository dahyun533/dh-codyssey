* AI에게 전달한 요청: 도움말 버튼 여백 두기, 처음으로 돌아가기에 마우스를 올리면 빨간 굵은 '처음으로 돌아가면 기록이 저장되지 않아요!' + 흰 글씨 둘째 줄 말풍선, 힐링하기 말풍선 안 잘리게
* 수정 후 테스트 결과: 처음으로 돌아가기 말풍선이 버튼 위에 나오고, 왼쪽·오른쪽 끝 버튼 말풍선이 버튼 끝에 맞춰 화면 안에 들어옴
* 수정 이유: 실수로 기록을 잃지 않게 미리 알려 주려고

* 수정 이유: 창을 단순하게, 단위 뜻을 필요할 때만 보이게

### 수정 기록 33

* 발견한 문제: 굽기를 시작해도 슬라이더 창 제목이 '반죽을 만들어요!' 그대로라 지금 상태를 알 수 없음
* AI에게 전달한 요청: 굽는 중 제목·부제목 바꾸기
* 수정 후 테스트 결과: 굽는 중 '단풍나무를 굽는 중이에요!' + '같은 반죽이라도 더 구울수록 단풍이 달라져요', 굽기 끝나면 '갓 구운 단풍나무를 살펴보고 더 구울지 정해요'로 바뀜
* 수정 이유: 단계별 상태 안내

### 수정 기록 34

* 발견한 문제: 슬라이더 창을 '반죽'이라 부르는데 경고는 '날씨를 바꿀 수 없어요'라 말이 안 맞음. 굽기 전에 반죽이 잠긴다는 걸 모름
* AI에게 전달한 요청: 경고를 '반죽을 바꿀 수 없어요'로, 굽기 버튼 말풍선 '굽기 시작하면 반죽을 바꿀 수 없어요. / 마음에 드는 반죽이 준비됐나요?'
* 수정 후 테스트 결과: 굽는 중 경고가 '굽는 중에는 반죽을 바꿀 수 없어요.'로 나오고, 굽기 버튼에 마우스를 올리면 빨간 굵은 첫 줄 + 검은 둘째 줄 말풍선이 나옴
* 수정 이유: 용어 통일, 굽기 전에 미리 알려 주기

### 수정 기록 35

* 발견한 문제: 굽기 완료 질문 글씨·버튼 색이 슬라이더 창 다른 글씨와 다름
* AI에게 전달한 요청: 완료 질문 창도 남보라로
* 수정 후 테스트 결과: 윗줄·완료·더 굽기 버튼은 짙은 남보라, 아랫줄은 조금 연한 남보라로 나옴
* 수정 이유: 창 안 글씨 색 통일

### 수정 기록 36

* 발견한 문제: 전체 화면(가로로 넓은 창)에서 위아래 여백이 여전히 좁아 답답함
* AI에게 전달한 요청: 전체 화면 여백 더 넉넉하게 (두 번 요청)
* 수정 후 테스트 결과: 넓은 창에서도 1:1 창처럼 사방에 여유가 생김. 세로로 긴 창은 그대로
* 수정 이유: 어떤 화면 크기에서도 편안한 배치

## 사용자 테스트

* 테스트 참여자와 요청한 작업: 제작자 본인이 처음 쓰는 사용자 입장에서 v1 페이지를 직접 사용함. 요청한 작업은 날씨 반죽 고르기 → 굽기 → 더 굽기 → 결과 설명 읽기 → 힐링하기 → 처음으로 돌아가기까지 한 바퀴 해 보기. 아래 수정 기록 중 사용하면서 헷갈리거나 불편했던 부분에서 나온 것만 사용자 테스트로 묶음
* 사용자의 행동과 질문:

  * 수정 기록 7: 결과 화면에서 '처음으로 돌아가기'를 누르려다 "누르면 지금 결과는 어떻게 되지?" 하고 멈춤
  * 수정 기록 15: 바람 단계 설명 '1초에 4m보다 느린 바람'을 읽고 "그래서 어느 정도 바람이야?" 하고 감이 안 옴
  * 수정 기록 18: '평년'이라는 말을 보고 뜻을 바로 이해하지 못함
  * 수정 기록 19: 10일 구운 뒤 '굽기 완료할 건가요?'를 보고 빨리 끝내라고 다그치는 느낌을 받음
  * 수정 기록 22: 힐링하기로 나무를 보려는데 버튼 줄이 나무 앞을 가림
  * 수정 기록 28: 30일을 다 채웠는데도 더 구울 수 있냐는 식의 질문이 나와 "다 구운 거 아냐?" 하고 헷갈림
  * 수정 기록 34: 굽기를 누른 뒤에야 반죽을 바꿀 수 없다는 걸 알게 됨. 슬라이더 창은 '반죽'인데 경고는 '날씨'라고 해서 말이 안 맞음
* 받은 피드백:

  * 기록이 사라지는 버튼은 누르기 전에 미리 알려 줘야 함
  * 숫자만 있는 설명, 어려운 낱말('평년')은 초등학생이 이해하기 어려움
  * 안내 문구 말투가 부드러워야 부담 없이 고를 수 있음
  * 힐링 모드에서는 나무만 편하게 보고 싶음
  * 상황(30일 다 채움, 굽기 시작)에 맞는 안내가 필요하고, 같은 대상은 같은 말로 불러야 함
* 반영 내용과 결과:

  * 처음으로 돌아가기에 마우스를 올리면 빨간 '처음으로 돌아가면 기록이 저장되지 않아요!' 말풍선이 나옴 (수정 기록 7)
  * 바람 1\~3단계를 '나뭇잎이 살랑살랑 흔들리는 바람'처럼 일상 말로, '평년' → '평소'로 바꿈 (수정 기록 15, 18)
  * '굽기 완료할 건가요?' → '지금 완료해도 좋고, 조금 더 구워도 좋아요'로 바꿈 (수정 기록 19)
  * 힐링 중에는 버튼 줄이 거의 투명해지고 마우스를 올린 버튼만 또렷해짐 (수정 기록 22)
  * 30일을 채우면 '30일 모두 구웠어요.' + '결과를 확인해 보세요!'가 나옴 (수정 기록 28)
  * 굽기 버튼에 '굽기 시작하면 반죽을 바꿀 수 없어요.' 말풍선 추가, 경고를 '굽는 중에는 반죽을 바꿀 수 없어요.'로 통일 (수정 기록 34)
  * 결과: 다시 한 바퀴 사용해 봤을 때 같은 곳에서 멈추거나 헷갈리지 않음. v2 HTML에 모두 반영됨
