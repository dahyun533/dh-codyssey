# PlayHub 작업로그

- 서비스: PlayHub (여러 게임이 모인 게임 플랫폼, 데스크탑 웹 16:9)
- 레퍼런스: 외부 디자인·이미지 사용 안 함. 2·3번 화면은 내가 만든 1번 화면(수정본)을 같은 ChatGPT 대화 안에서 스타일 레퍼런스로 사용

## 사용한 도구
| 도구 | 쓴 곳 | 쓴 이유 |
|---|---|---|
| ChatGPT 이미지 생성 | 화면 이미지 생성 | Midjourney는 구독이 없어 생성 불가 → 무료로 바로 쓸 수 있고 대화로 앞 이미지를 이어 받을 수 있어 선택 |
| Python (Pillow) | 후가공 (아바타 화면 아이템 칸 교체) | 아이템 칸을 같은 크기로 정확히 잘라 붙이고 색만 바꾸는 작업이라 픽셀 단위로 편집 가능한 도구 사용. 원본 해상도(1672×941) 그대로 유지 |
| Figma | 화면 배치, Hotspot·화면 전환 (프로토타입) | 미션 권장 도구 |
| Claude (Claude Code) | 기획 질문, 프롬프트 작성·수정, ChatGPT 입력과 결과 확인, 후가공 코드 작성, Figma 배치·Hotspot 연결(Figma 플러그인 API) 보조 | AI 협업 워크플로우 실습. 판단(서비스·색·화면 구성·수정 여부)은 내가 함 |

```
Create an image: game platform website game list page UI, PlayHub, white background, purple mint orange, genre tabs, grid of game cards, 16:9 landscape
Create an image: game platform website avatar customization page UI, PlayHub, white background, purple mint orange, cute round 3D character, item panel, 16:9 landscape
```

  - 글자는 대체로 깔끔함
  - 보라색이 너무 많고 빨강·초록·파랑 등 다른 색이 섞임 → 3색 규칙 안 지켜짐

## 4. 프로토타입 (Figma)
- 파일: PlayHub UI 시안
- 프레임 3개(1 홈 / 2 게임 목록 / 3 내 아바타)에 최종 이미지 배치. 홈을 위에, 목록·아바타를 아래에 두어 흐름이 한눈에 보이게 함
- 투명 Hotspot 12개에 클릭 → 화면 이동(Dissolve) 연결, 흐름 시작점 = 1 홈
  - 홈: Games 메뉴·Play Now·View More → 목록 / Avatar 메뉴·프로필 → 아바타
  - 목록: 로고·Home → 홈 / Avatar·프로필 → 아바타
  - 아바타: 로고·Home → 홈 / Games → 목록
- 캡처: `figma/화면흐름_Hotspot.png`

## 5. 배운 점
- 단어만 나열하면 AI가 빈 곳을 마음대로 채움 → 메뉴·글자·색을 정확히 적을수록 결과가 기획과 맞아짐
- 색은 이름보다 HEX + "ONLY"가 잘 지켜짐
- 일관성 유지 방법은 크게 두 가지
  - 시드 고정: 같은 시드(무작위 출발값)를 쓰면 비슷한 그림이 나오게 하는 방법. Midjourney(`--seed`)·Stable Diffusion에는 있지만 ChatGPT 이미지 생성에는 시드 설정이 없음
  - 이미지 레퍼런스: 이미 만든 이미지를 기준으로 주고 "같은 스타일"을 요청하는 방법 → 이번엔 이 방법 사용. 첫 화면을 레퍼런스로 이어 쓰고, 캐릭터 생김새를 매번 같은 문장으로 적어서 유지함
