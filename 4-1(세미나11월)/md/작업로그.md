# PlayHub 작업로그

- 서비스: PlayHub (여러 게임이 모인 게임 플랫폼, 데스크탑 웹 16:9)
- 이미지 생성: ChatGPT 이미지 생성 (Midjourney는 구독이 없어 변경)
- 후가공·프로토타입: Figma
- 레퍼런스: 외부 이미지 사용 안 함. 2·3번 화면은 내가 만든 1번 화면(v2)을 스타일 레퍼런스로 사용

## 1. 초안 (v1)

```
Create an image: game platform website home page UI, PlayHub logo, white background, purple mint orange, banner, game cards, 16:9 landscape
Create an image: game platform website game list page UI, PlayHub, white background, purple mint orange, genre tabs, grid of game cards, 16:9 landscape
Create an image: game platform website avatar customization page UI, PlayHub, white background, purple mint orange, cute round 3D character, item panel, 16:9 landscape
```

- 의도: 핵심 단어만 넣고 AI 해석 확인
- 결과 (대화 캡처 1~3)
  - 글자는 대체로 깔끔함
  - 보라색이 너무 많고 빨강·초록·파랑 등 다른 색이 섞임 → 3색 규칙 안 지켜짐
  - 메뉴가 화면마다 다름 (Top Charts / Collections / Rewards / Community 등 기획에 없는 메뉴)
  - 홈 배너 캐릭터는 사람 소년, 아바타 화면은 둥근 캐릭터 → 화면끼리 캐릭터가 다름
  - 기존 게임을 떠올리게 하는 초록 파이프·? 블록이 들어감

## 2. 수정 (v2)

### 바꾼 것과 이유
| 바꾼 것 | 이유 |
|---|---|
| 메뉴를 'Home / Games / Avatar'로 정확히 지정 | 화면마다 메뉴가 달라서 |
| 색을 HEX로 지정 + "ONLY three accent colors, no other colors" | 다른 색이 섞여서 |
| 마스코트 모습 고정 (둥근 3D, 보라 후드, 민트 모자, 헤드폰) | 화면마다 캐릭터가 달라서 |
| "no pipes, no question-mark blocks, no existing games or brands" | 기존 게임과 비슷한 요소 제거(저작권) |
| 들어갈 글자를 따옴표로 지정 ('Play Together', 'Popular Games' 등), 짧은 영어만 | 글자 깨짐 줄이기 |
| 2·3번 화면은 "use the previous PlayHub image as the style reference" | 세 화면 일관성 유지(이미지 레퍼런스) |

## 4. 프로토타입 (Figma)
- 프레임 3개(1 홈 / 2 게임 목록 / 3 내 아바타)에 이미지 배치
- 투명 Hotspot 12개에 클릭 → 화면 이동(Dissolve) 연결, 흐름 시작점 = 1 홈
  - 홈: Games 메뉴·Play Now·View More → 목록 / Avatar 메뉴·프로필 → 아바타
  - 목록: 로고·Home → 홈 / Avatar·프로필 → 아바타
  - 아바타: 로고·Home → 홈 / Games → 목록
- 캡처: `figma/화면흐름_Hotspot.png`

## 5. 배운 점
- 단어만 나열하면 AI가 빈 곳을 마음대로 채움 → 메뉴·글자·색을 정확히 적을수록 결과가 기획과 맞아짐
- 색은 이름보다 HEX + "ONLY"가 잘 지켜짐
- 일관성은 첫 화면을 레퍼런스로 이어 쓰고, 캐릭터 생김새를 매번 같은 문장으로 적어서 유지함
