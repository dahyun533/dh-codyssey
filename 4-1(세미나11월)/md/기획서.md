# PlayHub 기획서

## 누가 쓰나
- 10~30대 게임 이용자
- 여러 게임을 한 곳에서 찾고 바로 플레이하고 싶은 사람

## 무엇을 하려고
- 여러 게임이 모인 플랫폼에서 게임 찾기 → 고르기 → 내 아바타 꾸미기를 한 흐름으로 보여 줌
- 로블록스 같은 "게임 모음" 서비스이지만 이름·로고·캐릭터는 새로 만듦

## 화면과 동작
- 비율: 데스크탑 16:9 웹 화면
- 화면 1 홈
  - 상단 메뉴(로고 PlayHub, 홈 / 게임 / 아바타, 검색창, 프로필)
  - 큰 추천 배너 1개 + 인기 게임 카드 한 줄
  - 동작: 배너·"게임" 메뉴 클릭 → 게임 목록, 프로필·"아바타" 메뉴 클릭 → 내 아바타
- 화면 2 게임 목록
  - 장르 탭(전체 / 액션 / 퍼즐 / 레이싱 / 롤플레이)
  - 장르별 게임 카드 격자(썸네일, 게임 이름, 플레이 수)
  - 동작: 로고 클릭 → 홈, "아바타" 메뉴 → 내 아바타
- 화면 3 내 아바타
  - 가운데 큰 아바타 미리보기
  - 옆에 꾸미기 패널(모자 / 옷 / 신발 / 색상 탭, 아이템 격자, 저장 버튼)
  - 동작: 로고 클릭 → 홈, "게임" 메뉴 → 게임 목록

## 디자인
- 화이트톤 배경, 포인트 색 3개만 사용: 보라(메인 버튼), 민트(보조 강조), 주황(배지·알림)
- 둥근 카드, 넉넉한 여백
- 캐릭터: 둥근 3D 장난감 같은 캐릭터(블록형 아님)

## 필요한 자료
- 이미지 생성: ChatGPT 이미지 생성 (Midjourney는 구독이 없어 변경)
- 후가공·프로토타입: Figma
- 게임 썸네일·캐릭터는 모두 AI로 새로 생성(타인 작업물 캡처 사용 안 함)

## 완성 기준
- 16:9 화면 이미지 3장, 세 화면의 색·캐릭터 스타일이 같아 보임
- 이미지 속 깨진 글자 없음(필요하면 Figma에서 글자 교체)
- Figma에서 메뉴·배너·로고 클릭 시 화면 이동 가능
- 프롬프트 초안 → 수정 → 최종 과정과 바꾼 이유가 작업로그에 기록됨
