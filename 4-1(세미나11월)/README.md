# [세미나 A] AI 기반 UI/UX 디자인 시안 제작 — PlayHub

여러 게임이 모인 게임 플랫폼 PlayHub의 데스크탑 웹(16:9) 시안.

## 사용한 도구
- 이미지 생성: ChatGPT 이미지 생성
- 후가공·프로토타입: Figma

## 화면 흐름
- 홈 → 'Games' 메뉴 / 'Play Now' → 게임 목록
- 홈·목록 → 'Avatar' 메뉴 / 프로필 → 내 아바타
- 모든 화면 → 'PlayHub' 로고 → 홈
