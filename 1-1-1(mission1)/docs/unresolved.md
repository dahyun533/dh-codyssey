# 1-1-1 미해결 기록

프롬프트를 고쳐도 끝내 원하는 결과가 안 나온 과업만 적음. 성공한 시도는 적지 않음.

<details>
<summary><b>1. 출처로 적은 문서가 실제로 있는지 확인하기</b></summary>

<blockquote>

시도한 프롬프트:
- v1 금지 사항: "링크를 쓰지 않는다. 출처는 문서·책 이름과 검색어만 쓴다."
- v2 금지 사항: "미션지에 정의가 없는 용어도 뜻을 비우지 않는다. 일반적인 뜻을 한 문장으로 쓰고 "(미션지에 정의 없음, 확인 필요)"를 붙인다."
- v2 작업 순서 3단계: "베이컨 | 용어의 정의와 출처를 찾는다. 확인하지 못한 것은 "확인 필요"로 남긴다"
- v2 양식 1: "출처: {뜻을 확인할 문서·책 이름. 미션지에 정의가 있으면 미션지 섹션} / 검색어: {검색어 1}, {검색어 2}"

받은 결과:
- Zero-shot: 미션지 밖 출처(Brown 외 2020, Wei 외 2022, Anthropic 프롬프트 엔지니어링 문서)를 적음
- Few-shot: 출처를 미션지 위치로만 적어서, 정의 없는 용어는 확인하러 갈 곳이 없어짐
- v2: 정의 없는 용어에 다시 바깥 출처(위키백과 영어판 "Large language model", Brown 외 2020, Wei 외 2022, Anthropic "Prompt engineering overview", GitHub Docs "About repositories")를 적음. 확인하러 갈 곳은 생겼지만, 그 문서가 실제로 있는지와 적힌 뜻이 문서 내용과 같은지는 모델 답만으로 알 수 없음
- v3: v2와 같은 출처를 적음. 출처 규칙은 v3에서 바꾸지 않음

막힌 이유:
- 프롬프트로 바꿀 수 있는 건 출처를 적는 자리와 모양뿐임. 모델은 자기가 적은 문서가 실제로 있는지 스스로 확인하지 못함. 그래서 검색어로 문서를 찾아 뜻을 대조하는 일은 사람이 직접 해야 함

</blockquote>

</details>

<details>
<summary><b>2. 미션지에 정의가 없는 용어의 뜻이 맞는지 확인하기</b></summary>

<blockquote>

시도한 프롬프트:
- v1 금지 사항: "미션지에 없는 조건, 숫자, 날짜를 만들지 않는다. 모르면 "미션지에 없음, 확인 필요"라고 쓰고 확인할 곳을 적는다."
- v1 출력 전 점검: "용어의 결론(정의)과 예시가 그 용어의 뜻과 맞는지 확인했다. 미션지에 정의가 없는 용어는 "확인 필요"를 붙였다."
- v2 금지 사항: "미션지에 정의가 없는 용어도 뜻을 비우지 않는다. 일반적인 뜻을 한 문장으로 쓰고 "(미션지에 정의 없음, 확인 필요)"를 붙인다."

받은 결과:
- 모델 비교: ChatGPT는 정의 없는 용어의 뜻을 비우고 "확인 필요"만 씀. Gemini는 꼬리표 없이 뜻을 적음
- Zero-shot, Few-shot, v2, v3: 정의 없는 용어마다 뜻 한 문장과 "(미션지에 정의 없음, 확인 필요)"가 붙음. 꼬리표는 지켜짐
- 같은 용어인데 실행마다 뜻이 다르게 나옴
  - 시스템 프롬프트: "AI가 따를 역할과 규칙을 미리 주는 지시문"(Zero-shot) / "대화 내내 AI가 따르는 기본 지시문"(Few-shot) / "대화를 시작할 때 한 번 넣어 대화 내내 따르게 하는 지시문"(v2, v3)
  - 단계적 추론 유도: "생각을 단계별로 밟게 하는 지시를 더하는 방법"(Zero-shot) / "생각 과정을 단계별로 적게 하는 방법"(v2, v3)
- 어느 뜻이 이 미션에서 말하는 뜻인지는 모델 답만으로 알 수 없음

막힌 이유:
- 프롬프트로 바꿀 수 있는 건 뜻을 비우지 않게 하고 꼬리표를 붙이게 하는 것뿐임. 미션지에 정의가 없으니 모델이 맞춰 볼 기준이 없고, 그래서 실행마다 뜻이 조금씩 달라짐. 그 뜻이 미션이 말하는 뜻과 같은지는 사람이 자료를 찾아 대조하거나 운영진에게 물어 확인해야 함

</blockquote>

</details>
