|완성 기준|한 행동|결과|됨 / 안 됨|
|-|-|-|-|
|영화가 한 칸에만 있고, 옮긴 칸에 남음|카드 누르고 등급 누르기, 끌어 놓기|옮긴 칸에만 있고 그대로 남음|됨|
|제목 입력하면 새 카드 생김|제목 입력 후 '추가'|아직 안 정한 영화에 카드 생김|됨|
|다시 열어도 영화와 등급이 남음|등급 나눈 뒤 새로고침|모두 미분류로 돌아감|안 됨|
|화면 폭 좁아져도 오른쪽 안 잘림|브라우저 창 폭 좁히기|오른쪽이 잘려서 안 보임|안 됨|
|'처음으로' → 처음 8개 모두 미분류|영화 추가·배치 후 '처음으로'|8개 모두 미분류, 추가한 영화는 사라짐|됨|
|외부 파일·로그인 없이 HTML 한 장으로 열림|파일 더블클릭|바로 열림|됨|
|(기획서에 없음) '선택한 영화 되돌리기' 사용|카드 안 고르고 '선택한 영화 되돌리기' 누르기|안 움직이고 아래 회색 작은 글씨로만 "먼저 영화 카드를 골라 주세요"가 떠서 눈에 잘 안 띔|불편|
|(기획서에 없음) 추가한 영화 지우기|영화 추가 후 그 카드만 지우려고 해 보기|지우는 버튼이나 방법이 없음|불편|

## 받은 의견 확인

|받은 의견|직접 해 본 결과|반영 / 보류 / 되묻기|이유 (되묻기라면 물을 질문)|
|-|-|-|-|
|AI 1. 저장 기능 없음|등급 나눈 뒤 파일을 닫았다가 열었더니 모두 미분류로 돌아감|반영|저장 기능이 없으면 다시 열 때마다 처음부터 다시 나눠야 함 → 추가하면 다시 열어도 나눠 둔 등급이 그대로 남아, 새로 본 영화만 추가해서 취향 정리를 이어 갈 수 있음|
|AI 2. '처음으로'가 추가한 영화를 안 지움|영화 추가 후 '처음으로' 눌렀더니 추가한 영화도 지워짐|되묻기|직접 해 보니 추가한 영화가 등급표와 미분류 양쪽에서 모두 지워졌어요. 혹시 둘 중 한쪽에 남아 있었다는 말씀이실까요?|
|AI 3. 빈 제목 카드가 생김|제목 비우고 '추가' 눌렀더니 글자 없는 카드가 생김|반영|빈 제목을 막지 않으면 무슨 영화인지 모르는 카드가 쌓임 → 막으면 목록에 이름 없는 카드가 섞이지 않아, 어떤 영화를 어느 등급에 뒀는지 헷갈리지 않음|
|동료 1. 휴대폰으로 열면 불편|화면 폭 좁혔더니 오른쪽이 잘림|반영|화면 폭에 맞추지 않으면 휴대폰에서 오른쪽 칸과 카드가 잘려 못 씀 → 맞추면 휴대폰으로 열어도 다 보여, 컴퓨터 없이도 친구들과 바로 같이 쓸 수 있음|
|동료 2. 카드 옮기는 게 처음엔 헷갈림|위 설명은 'S·A·B·C 네 칸으로 나눠 보세요'뿐이라 옮기는 방법이 잘 안 보임|반영|사용법 안내가 없으면 처음 여는 사람이 카드 옮기는 방법을 몰라 헤맴 → 추가하면 처음 여는 친구도 바로 알아, 설명해 주지 않아도 혼자 티어리스트를 만들 수 있음|
|동료 3. 끌어서 옮기기 불편, 목록을 위나 옆으로|끌어서 S칸까지 잘 옮겨짐. 카드 누르고 등급 눌러도 옮겨짐|되묻기|카드를 누르고 등급을 누르면 끌지 않아도 옮겨져요. 이 방법을 안내에서 더 눈에 띄게 알려 주면 편하실까요?|
|동료 4. 카드 색이 칙칙함|카드가 회색 바탕임|되묻기|카드가 회색이라 칙칙하게 느끼셨군요. 지금보다 밝은 색을 말씀하신 걸까요, 아니면 다른 색감을 생각하신 걸까요?|
|동료 5. 포스터 사진 넣기|지금은 제목 글자만 있음|반영|포스터가 없으면 제목 글자를 하나하나 읽어야 영화를 찾음 → 추가하면 포스터만 보고 바로 알아봐, 카드를 빠르게 찾아 옮길 수 있고 화면도 더 보기 좋아짐|
|동료 6. C칸 없어도 될 듯|C칸이 존재함|보류|C칸이 없으면 아쉬웠던 영화를 둘 곳이 없음 → 그대로 두면 아쉬운 영화도 따로 모아 볼 수 있어, 좋아하는 것과 아닌 것까지 내 취향을 빠짐없이 정리할 수 있음|

* 아무도 말하지 않았는데 내가 찾은 것:

  * '선택한 영화 되돌리기'는 작동하지만, 먼저 카드를 고르라는 안내가 눈에 잘 안 띔 
  * 추가한 영화를 지우는 기능이 없음
