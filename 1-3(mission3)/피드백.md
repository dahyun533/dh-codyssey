# 민수 님께 보내는 피드백

## 잘된 점

### 기획서 완성 기준대로 된 것

* 카드 누르고 등급 누르기, 끌어 놓기 둘 다 옮긴 칸에만 들어가고 그대로 남음
* 제목 입력하고 '추가' 누르면 아직 안 정한 영화에 새 카드가 생김
* '처음으로' 누르면 처음 8개가 모두 미분류로 돌아감
* 외부 파일·로그인 없이 HTML 한 장으로 바로 열림

### 기획서에 없지만 좋았던 것

* 등급마다 색이 달라 어느 칸인지 한눈에 보임
* 등급 글자 아래 '최고·좋음·보통·아쉬움' 설명이 있어 뜻을 바로 알 수 있음
* 위에 'N편 중 M편 나눔'이 나와서 얼마나 남았는지 알 수 있음
* 카드를 끌 때 놓을 칸 색이 바뀌어 어디에 놓이는지 알 수 있음
* 고른 카드에 테두리가 생겨 무엇을 골랐는지 보임
* 옮기거나 추가할 때마다 "'기생충'을 S에 놓았어요"처럼 결과를 알려 줌
* 빈 칸에는 '여기로 끌어 놓기', 다 나누면 '모든 영화를 나눴어요'가 떠서 상태를 알 수 있음
* 제목 입력 후 Enter만 눌러도 추가됨
* '선택한 영화 되돌리기'로 잘못 옮긴 영화를 미분류로 되돌릴 수 있음

## 고치면 좋을 점

### 1\. 저장 기능 없음 (AI 1)

* 본 것: 등급 나눈 뒤 파일 다시 열었더니 모두 미분류로 돌아감
* 기준: 기획서 '같은 파일을 다시 열어도 영화와 등급이 남습니다'
* 제안: 배치를 브라우저에 저장해 주세요! → 파일을 닫았다 다시 열어도 나눠 둔 등급이 그대로 남아 있어요.

  * 카드를 S칸으로 옮기거나 새 영화를 추가하면 그 순간 브라우저에 저장되고, 파일을 다시 열면 저장된 배치대로 카드가 놓인 채로 열리면 좋겠어요.
  * '처음으로'를 누르면 저장된 내용도 함께 지워져서, 다시 열었을 때 처음 영화 8개가 모두 미분류에 있는 상태로 열리면 좋겠어요.

### 2\. 빈 제목 카드가 생김 (AI 3)

* 본 것: 제목 비우고 '추가' 눌렀더니 글자 없는 카드가 생김
* 기준: 기획서 '제목을 입력하고 '추가'를 누르면 카드가 생깁니다'
* 제안: 제목이 비어 있으면 카드를 만들지 말아 주세요! → 제목 칸을 비운 채 '추가'를 눌러도 미분류에 글자 없는 카드가 생기지 않아요.

  * 제목 칸이 비어 있거나 띄어쓰기만 있는 채로 '추가'를 누르면, 아래 안내 줄에 "추가할 영화 제목을 입력해 주세요"가 강조되어 뜨면 좋겠어요.
  * 그와 동시에 커서가 제목 칸으로 돌아가서, 칸을 다시 누르지 않고 바로 제목을 입력할 수 있으면 좋겠어요.

### 3\. 휴대폰으로 열면 불편 (동료 1)

* 본 것: 창 폭 좁혔더니 오른쪽이 잘림
* 기준: 기획서 '화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다'
* 제안: 화면 폭에 맞춰 페이지가 함께 줄어들게 해 주세요! → 휴대폰으로 열어도 등급 칸과 카드가 잘리지 않고 화면 안에 다 보여요.

  * 지금은 페이지 폭이 고정되어 있어서, 창을 그보다 좁히면 오른쪽 카드와 칸이 화면 밖으로 밀려나 잘리는 것 같아요.
  * 창을 좁히면 한 줄에 다 안 들어가는 카드가 자동으로 다음 줄로 내려가면 좋겠어요.
  * 휴대폰 폭이 되면 제목과 'N편 중 M편 나눔'이 위아래로 나뉘고, 등급 글자 칸도 좁아져서 카드 놓을 자리가 더 넓어지면 좋겠어요.

### 4\. 카드 옮기는 게 처음엔 헷갈림 (동료 2)

* 본 것: 위 설명이 'S·A·B·C 네 칸으로 나눠 보세요'뿐이라 옮기는 방법을 알기 어려움.
* 기준: 쓰다가 불편했던 점
* 제안: 처음 열었을 때 짧은 튜토리얼을 보여 주세요! → 파일을 처음 연 사람도 튜토리얼을 따라 카드 하나를 직접 옮겨 보면서 옮기는 방법을 익힐 수 있어요.

  * 파일을 처음 열면 미분류 카드 옆에 "영화 카드를 눌러 골라 보세요" 말풍선이 뜨고, 카드를 누르면 S·A·B·C 글자 옆에 "이제 등급 글자를 누르면 그 칸으로 옮겨져요"가 뜨면 좋겠어요.
  * 카드가 옮겨지면 마지막으로 "카드를 끌어다 놓아도 돼요"가 뜨고, '건너뛰기'나 '다시 보지 않기'를 누르면 바로 닫히면 좋겠어요.
  * 위쪽에 '사용법' 버튼이 있어서, 누르면 같은 말풍선이 처음부터 다시 뜨면 좋겠어요.

### 5\. 포스터 사진 넣기 (동료 5)

* 본 것: 카드에 제목 글자만 있고 포스터가 없음
* 기준: 쓰다가 불편했던 점
* 제안: 카드에 포스터를 함께 넣어 주세요! → 카드에 포스터 그림이 보여서 제목 글자를 읽지 않아도 어떤 영화인지 알아볼 수 있어요.

  * 무료 영화 정보 API인 TMDB를 쓰면, 영화 제목으로 검색해서 받은 포스터 주소를 카드에 넣어 파일을 열 때 포스터가 자동으로 불러와지면 좋겠어요.
  * 직접 추가한 영화도 '추가'를 누르는 순간 TMDB에서 같은 제목을 찾아 포스터가 함께 붙으면 좋겠어요.
  * 인터넷이 안 되거나 TMDB에서 못 찾은 영화는 지금처럼 제목만 있는 카드로 보이면 좋겠어요.

### 6\. 먼저 카드를 고르라는 안내가 잘 안 보임 (내가 찾은 것)

* 본 것: '선택한 영화 되돌리기'는 작동하지만, 먼저 카드를 고르라는 안내가 눈에 잘 안 띔
* 기준: 쓰다가 불편했던 점
* 제안: "먼저 영화 카드를 골라 주세요" 안내를 강조해 주세요! → 카드를 고르지 않고 버튼을 눌렀을 때, 카드를 먼저 골라야 한다는 걸 바로 알아챌 수 있어요.

  * 지금은 카드를 고르지 않고 '선택한 영화 되돌리기'나 등급 글자를 누르면, 아무것도 안 움직이고 아래 안내 줄 글자만 회색 작은 글씨로 바뀌어서 놓치기 쉬워요.
  * 이때 안내 줄의 "먼저 영화 카드를 골라 주세요"가 빨간 굵은 글씨로 2\~3초 동안 바뀌어 보이면 좋겠어요.

### 7\. 추가한 영화를 지우는 기능이 없음 (내가 찾은 것)

* 본 것: 추가한 영화를 지우는 기능이 없음
* 기준: 쓰다가 불편했던 점
* 제안: 직접 추가한 카드에 작은 '×' 버튼을 달아 주세요! → 잘못 추가한 카드를 '처음으로'로 전부 되돌리지 않고 그 카드 하나만 지울 수 있어요.

  * 직접 추가한 카드 오른쪽 위에 작은 '×'가 보이고, 누르면 그 카드만 화면에서 사라지면 좋겠어요.
  * '×'를 누르면 바로 지워지지 않고 "'○○'를 지울까요?" 확인 창이 먼저 떠서, '확인'을 눌러야 지워지면 좋겠어요.
