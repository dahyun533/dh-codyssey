## 점검 결과
- 깨진 글자: 세 장 모두 메뉴·제목·카드·버튼 글자 확대 확인 → 없음
  - 2단계(수정) 프롬프트에서 들어갈 글자를 따옴표로 지정하고 짧은 영어만 쓰게 한 효과
- 부자연스러운 요소: 2건 (아바타 화면 아이템 칸, 세 화면 상단 메뉴 위치 불일치)

## 수정 1. 아바타 화면 아이템 칸
- 문제: 'Hat' 탭이 선택됐는데 아래 줄에 후드티 3개·신발이 나옴 → 탭과 내용이 안 맞음
- 방법: 윗줄 비니·버킷햇 칸을 복사해 색만 보라·민트·주황으로 바꿔 아래 줄 4칸에 붙임 (Python Pillow. 칸을 픽셀 단위로 정확히 잘라 붙이고 원본 해상도를 유지하려고 Figma 대신 사용)
- 결과: 아래 줄이 보라 비니 / 민트 비니 / 주황 버킷햇 / 보라 버킷햇 → 8칸 모두 모자
- 파일: `아바타_수정전.png` → `아바타_수정후.png`, 한눈에 보기 `아바타_전후비교.png`

## 수정 2. 세 화면 상단 메뉴 통일
- 문제: 화면마다 상단 메뉴 위치가 조금씩 다름
  - 'Home' 글자 중심: 홈 481px / 목록 467px / 아바타 465px
  - 'Games' 글자 중심: 홈 645px / 목록 637px / 아바타 624px
  - 활성 메뉴 보라 칸 너비: Home 151px / Games 160px / Avatar 174px
  - → 프로토타입에서 메뉴를 누를 때마다 메뉴 줄이 흔들려 보임. 상단 메뉴가 화면 이동의 핵심이라 눈에 띄는 문제
- 방법 (Python Pillow)
  - 홈 화면 상단 메뉴 바(로고·검색창·프로필)를 세 화면에 똑같이 사용
  - 메뉴 3개를 같은 좌표에 배치: Home 481px / Games 645px / Avatar 804px (홈 화면 기준)
  - 활성 메뉴 보라 칸을 같은 크기(170×50px)로 새로 그리고, 각 화면 원래 이미지의 흰 글자를 같은 높이로 맞춰 얹음
  - 홈은 Home, 목록은 Games, 아바타는 Avatar만 보라 칸
- 결과: 화면을 넘겨도 메뉴 줄은 그대로이고 보라 칸만 옮겨 감 → 지금 어느 화면인지 분명해짐
- Figma: 이미지 교체 후 메뉴 Hotspot도 새 위치(170×50px)로 옮김
- 파일: `메뉴_수정전_화면1_홈.png` 등 3장 → `ui/` 최종본, 한눈에 보기 `메뉴_전후비교.png` (위 3줄 수정 전, 아래 3줄 수정 후)
- 화면 3은 수정 1을 마친 그림에서 메뉴를 고쳐서 `메뉴_수정전_화면3_아바타.png` = `아바타_수정후.png` (같은 파일)
