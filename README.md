## 1-1(mission1) 질문하며 기획하고 HTML 첫 버전 만들기

- **미션:** AI의 질문에 답하며 기획서를 정리하고, 같은 기획서로 두 AI에게 HTML 첫 버전을 받아 비교함.
- **한 것:** 영화 티어리스트 기획. S~D 5단계(무지개색), 끌어다 놓기, 새로고침 후 유지, 제목+이모지 카드로 정함. Claude(A)·ChatGPT(B)에게 같은 기획서로 HTML을 받아 같은 행동으로 비교함.
- **결과:** 수정 없이 모두 동작하고 기획서와 더 잘 맞는 A 선택. B는 저장 이미지에서 이모지가 제목에 겹쳐 따로 고침.

## 1-2(mission2) 오류를 재현하고, 본 대로 물어서 고치기

- **미션:** 오류를 직접 재현해 한 문장으로 좁히고, 본 그대로 AI에게 물어서 고침.
- **한 것:** 일부 영화 카드가 안 옮겨지는 오류를 발견. '해리포터'와 '해리 포터'를 비교해 원인을 '제목의 띄어쓰기'로 좁힘.
- **결과:** 카드 이름표가 띄어쓰기 앞까지만 읽히는 문제를 개발자 도구로 확인하고 고침. 띄어쓰기 있는 제목도 정상으로 옮겨짐.

## 1-3(mission3) 직접 써보고 피드백 주고받기

- **미션:** 동료의 페이지를 직접 써 보고 피드백을 보내고, 받은 의견을 하나씩 확인함.
- **한 것:** 완성 기준별로 직접 써 본 메모 작성. 받은 의견 9개를 직접 해 보고 반영 5·되묻기 3·보류 1로 정리함.
- **결과:** 민수 님께 보낼 피드백 작성. 아무도 말하지 않은 불편(되돌리기 안내가 안 보임, 추가한 영화 삭제 불가)도 찾아 적음.

## 1-4(mission4) 기능을 더하고 확인·복구를 반복하기

- **미션:** 새 기능을 더하고, 완성 기준으로 확인한 뒤 고치거나 원래 파일로 돌아감.
- **한 것:** 카드에 한 줄 메모 달기 기능 추가. '인생 영화', 'n차 관람' 같은 메모를 달고 싶어서 고름.
- **결과:** 첫 파일에서 메모 정렬과 칸 크기 문제를 찾아 한 번 고쳐 완성.

## 2-1(mission5) AI와 함께 HTML 페이지 기획서 작성하기

- **미션:** AI와 함께 새 HTML 페이지의 기획서를 작성함. 제출물은 기획서 1개.
- **한 것:** 날씨와 일수를 정해 단풍나무를 '구워' 보며 단풍 색이 바뀌는 원리를 배우는 '단풍나무 굽기' 기획.
- **결과:** 학술지·기상청 자료를 근거로 한 상세 기획서(v1)와 이를 짧게 줄인 요약 기획서 작성.

## 2-2(mission6) 두 AI로 HTML 만들고 테스트하기

- **미션:** 같은 기획서로 두 AI에게 HTML을 받아 같은 순서로 테스트하고, 고른 결과물을 고침.
- **한 것:** Claude(A)·ChatGPT(B) 비교. B는 굽는 중 경고 기능이 아예 작동하지 않아 A 선택. 직접 써 보며 36번 수정함.
- **결과:** 처음 쓰는 사람 입장에서 멈칫한 곳(어려운 낱말, 다그치는 말투, 기록이 사라지는 버튼 등)을 고쳐 v2 완성.

## 2-3(mission7) 테스트하며 고치고 사용자 피드백 반영하기

- **미션:** PC와 휴대폰에서 테스트하며 고치고, 사용자 피드백을 반영한 뒤 기획서를 최종 HTML에 맞게 수정함.
- **한 것:** 휴대폰 탭 안내, 터치 조작, 기기 비율에 맞춘 이미지 저장 등 18번 더 수정(총 54번). 피드백으로 나무를 누르면 잎이 떨어지고 다람쥐가 나오는 이스터에그 추가.
- **결과:** PC·휴대폰 모두 겹침·잘림·저장 문제 없이 끝까지 진행되는 v3 완성. 기획서도 v3에 맞게 완료 기준과 추가 기능을 고침.

## 파일 이름 규칙

- 폴더 안은 `html/`(페이지), `md/`(기획서·기록), `대화 캡처/`(AI와 나눈 주요 대화)로 나눔.
- 괄호 안은 내가 구분하려고 붙인 버전. 예: `기획서(v2).md` = 두 번째 기획서.
- `기획서(요약).md` = 상세 기획서를 짧게 줄인 기획서.
