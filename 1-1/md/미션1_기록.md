# 미션 1 기록

- AI A 이름 / 주요 대화 캡처 파일명: Claude / `A_v1_Claude_대화캡처1~4.png`
- AI B 이름 / 주요 대화 캡처 파일명: ChatGPT / `B_v1_ChatGPT_대화캡처.png`, `B_v2_ChatGPT_대화캡처1~2.png`
- AI가 물어서 내가 정한 것: 혼자 조작·결과는 이미지로 공유, S~D 5단계(무지개색), 끌어다 놓기만, 새로고침 후 유지, 제목+이모지 카드, 이름 없는 대기 칸
- 같은 행동으로 비교한 결과(해본 행동 → 기대 결과 → A의 결과 / B의 결과):
  - 끌기·순서 바꾸기·새로고침·추가·삭제·되돌리기 → 기대대로 동작 → A 성공 / B 성공
  - 결과 이미지 저장 → S~D만 담긴 PNG → A 성공 / B 이모지가 제목 위에 겹침
- 선택한 파일명과 고른 이유: `영화_A_v1_Claude.html` / 수정 없이 모두 동작했고, 대기 칸 이름 없음 등 기획서와 더 잘 맞음
